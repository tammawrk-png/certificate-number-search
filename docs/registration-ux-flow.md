# ลำดับ UX การสมัครสอบ

## Flow ของหน้าสาธารณะ

หน้านี้ออกแบบเป็น public working surface สำหรับโทรศัพท์เป็นหลัก นักเรียนไม่ต้องสร้างบัญชีและไม่ต้องกรอกชั้น ห้อง หรือครูที่ปรึกษาเอง

1. กรอกเลขประจำตัวนักเรียนเพื่อดูทะเบียนปัจจุบันและประวัติใบประกาศเดิม
2. ตรวจชื่อ ชั้น ห้อง ครูที่ปรึกษา เลขใบประกาศทุกระดับ และคำแนะนำว่า “ต้องสมัคร / แนะนำ / จบแล้ว / รอตรวจ”
3. ตรวจและแก้ไขข้อมูลส่วนตัวที่จำเป็นต่อแบบแม่กองธรรม แล้วกดบันทึกได้ทันที
4. กดเข้าสู่ขั้นสมัคร เลือกระดับตามคำแนะนำ ยืนยันข้อมูล ยินยอม และส่งใบสมัคร
5. ผู้ที่ไม่สอบต่อไม่ต้องยืนยันและไม่ต้องส่งแบบฟอร์มใด ๆ

`student_number` เป็นเพียงกุญแจเริ่มต้น ไม่ใช่หลักฐานว่าเลขประชาชนหรือวันเกิดถูกต้อง ระบบจึงไม่อ้างว่าฐานใบประกาศเดิมยืนยันข้อมูลเหล่านี้ได้ เพราะฐานเดิมมีเฉพาะเลขใบประกาศ ชื่อ ระดับ และปีสอบ ผู้สมัครต้องตรวจ/เติมข้อมูลส่วนตัวเองก่อนส่งฟอร์ม

ผู้ที่ไม่สอบต่อไม่ต้องเข้ามายืนยันหรือกรอกแบบฟอร์ม ระบบติดตามเฉพาะผู้สมัคร ส่วน ม.1 และ ม.4 ที่เป็นชั้นเริ่มต้นต้องสมัครชั้นตรีตามกติกาฝั่งเซิร์ฟเวอร์

## หลักการ

- นักเรียนไม่ต้องสร้างบัญชีและไม่ต้องล็อกอิน
- ใช้เลขประจำตัวนักเรียนเป็นตัวค้น แล้วให้เจ้าของยืนยันข้อมูลชื่อที่ระบบแสดง
- ไม่ให้กรอกชั้น ห้อง หรือครูที่ปรึกษาเอง เพราะข้อมูลเหล่านี้มาจาก roster ที่เจ้าหน้าที่ตรวจแล้ว
- ระบบไม่เปิดรับสมัครจากหน้าเว็บจนกว่าเจ้าหน้าที่จะเปิด `registration_windows`
- ก่อนส่งต้องเห็นสรุปข้อมูลและยืนยันความถูกต้อง

## ลำดับหน้าจอ

1. **ค้นประวัติ** — กรอกเลขประจำตัว ระบบค้นทะเบียนและประวัติใบประกาศ
2. **ตรวจข้อมูลของฉัน** — แสดงข้อมูลที่ต้องใช้ในฟอร์มและบันทึกการแก้ไขทันที
3. **เลือกสมัคร** — เลือกระดับตามคำแนะนำและส่งใบสมัครเมื่อเปิดรับสมัคร
4. **ผลการส่ง** — แสดงสถานะและเลขอ้างอิง

## การแยกข้อมูลในฐานข้อมูล

ใบสมัครผูกด้วย `academic_year_id + student_id + education_band + dhamma_level`
โดย `student_id` ผูกกับ classroom ของ roster ซึ่งเก็บสาย ชั้น ห้อง และครูที่ปรึกษาแยกต่างหาก
จึงไม่ต้องใช้บัญชีผู้ใช้ของนักเรียนเป็นตัวแยกข้อมูล และรองรับนักเรียนคนเดิมย้ายจาก ม.ต้นไป ม.ปลาย
โดยถือเป็นคนละสายตามนโยบายโรงเรียน และไม่ใช้ชื่อเป็นตัวแยกคำขอ

## สถานะที่นักเรียนเห็น

- `REGISTRATION_CLOSED`: ยังไม่เปิดช่วงรับสมัคร
- `STUDENT_NOT_VERIFIED`: เลขประจำตัวหรือชื่อไม่ตรงทะเบียน
- `BAND_MISMATCH`: เลือกสายไม่ตรงกับทะเบียนปัจจุบัน
- `RULE_NOT_FOUND`: ยังไม่มีกติกาสำหรับปี/สาย/ระดับดังกล่าว
- `SUBMITTED`: บันทึกใบสมัครสำเร็จ

เมื่อบันทึกสำเร็จ ระบบแสดงรหัสอ้างอิงรูปแบบ `ปีการศึกษา-รหัสสั้น` ที่สร้างจาก UUID ของใบสมัคร
เพื่อใช้ตรวจสอบภายหลัง โดยไม่ใช้เลขประจำตัวหรือชื่อเป็นรหัสอ้างอิง

## การออกแบบสำหรับมือถือ

- ใช้ wizard ทีละขั้น ลดจำนวนช่องที่เห็นพร้อมกัน
- ปุ่มถัดไป/ย้อนกลับเต็มความกว้างบนจอเล็ก
- ใช้ `inputmode="numeric"` กับเลขประจำตัว
- ยืนยันซ้ำก่อนส่ง และรักษาข้อความสถานะไว้ในหน้าเดียวกัน
- สีและสถานะใช้เป็นตัวช่วย ไม่ใช้สีอย่างเดียวในการสื่อความหมาย
