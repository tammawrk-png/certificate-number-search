# ขั้นตอนสร้างไฟล์แม่กองธรรม

ขั้นตอนนี้ใช้เมื่อเจ้าหน้าที่โหลดรายงานจากหน้า staff แล้ว ต้องสร้างไฟล์ `.xls` ตามต้นฉบับเดิม

## โหมดอัตโนมัติผ่าน GitHub Actions

workflow `Build Mother Sangha report` ใช้แบบ manual เท่านั้นและสร้างทีละระดับ เพื่อกันการรวมชั้นหรือยิงรายงานผิดปี ผู้ดูแลต้องตั้งค่าใน repository ก่อน:

- GitHub Secret `GOOGLE_SERVICE_ACCOUNT_JSON`: service account ที่ได้รับสิทธิ์เฉพาะโฟลเดอร์งาน
- GitHub Secret `SUPABASE_SERVICE_ROLE_KEY`: ใช้เฉพาะใน runner ไม่ใส่ในไฟล์หรือหน้าเว็บ
- GitHub Variables `DRIVE_SOURCE_FOLDER_ID` และ `DRIVE_OUTPUT_FOLDER_ID`: ใช้ ID ของโฟลเดอร์ที่กำหนดเท่านั้น

ต้องแชร์โฟลเดอร์ต้นฉบับและโฟลเดอร์รายงานให้ service account เป็นผู้แก้ไขเท่าที่จำเป็นก่อนเรียก workflow และไม่ควรให้ service account เห็น My Drive ทั้งหมด หลังตั้งค่าแล้วให้เลือก `Actions → Build Mother Sangha report → Run workflow` ระบุปีและระดับ ระบบจะหยุดเมื่อไม่มีข้อมูลสมัคร และจะอัปโหลดผลลัพธ์เฉพาะ `03_รายงานส่งออก`

1. เข้าหน้าเจ้าหน้าที่ด้วยบัญชีที่ได้รับอนุญาต แล้วกด `โหลดข้อมูลรายงาน`
2. เลือกระดับเดียวเท่านั้น แล้วดาวน์โหลด `JSON เติมแบบ` ของระดับนั้น
3. ดาวน์โหลดสำเนาต้นฉบับระดับเดียวกันจากโฟลเดอร์ Drive `00_ต้นฉบับฟอร์มแม่กองธรรม` ลงในโฟลเดอร์ชั่วคราว ห้ามแก้ชื่อหรือแก้ไฟล์ต้นฉบับบน Drive
4. เรียกใช้ `scripts/fill-mother-sangha-form.py` โดยระบุ template `.xls`, JSON และ output `.xls` คนละไฟล์ เช่น:

```sh
python3 scripts/fill-mother-sangha-form.py \
  "สำหรับนักเรียน-นักศึกษา-ฆราวาส-ศ.๕-ธรรมศึกษาชั้นตรี_2568-v3.xls" \
  dharma-ตรี-2569.json \
  dharma-ตรี-2569-filled.xls \
  --year 2569 --level ตรี
```

5. เปิดตรวจไฟล์ผลลัพธ์ด้วยโปรแกรมตารางข้อมูล ตรวจชื่อสนามสอบ ปี รหัสสนามสอบ จำนวนแถว ช่องประชาชน วันเกิด และช่องประโยคเดิมของโท/เอก ก่อนส่งจริง
6. อัปโหลดเฉพาะไฟล์ผลลัพธ์ไปยังโฟลเดอร์ Drive `03_รายงานส่งออก` โดยแยกชื่อไฟล์และระดับ ห้ามนำ output กลับไปเป็น template

สคริปต์จะหยุดทันทีถ้าชื่อชีต ชื่อฟอร์ม หัวคอลัมน์ หรือ merged range ไม่ตรง และจะปฏิเสธการเขียนทับต้นฉบับ ช่องที่ไม่มีข้อมูลจะเว้นว่างเพื่อให้เจ้าหน้าที่ตรวจทาน ไม่เติมข้อมูลเดาเอง
