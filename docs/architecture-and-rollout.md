# ระบบกิจกรรมธรรมศึกษา

## ขอบเขต

- คงระบบค้นเลขใบประกาศเดิมไว้โดยไม่เปลี่ยนพฤติกรรม
- Firebase เป็นประวัติเดิมแบบอ่านอย่างเดียว จำนวน 3,278 รายการ
- Supabase/PostgreSQL เป็นฐานข้อมูลหลักของระบบกิจกรรมใหม่
- อ่านรายชื่อนักเรียนจากไฟล์จริง แยกชั้น ห้อง และครูที่ปรึกษา
- ไม่นำเข้าห้อง 16 และข้อมูลนักเรียนที่ออกแล้ว
- Dashboard สาธารณะแสดงสถิติรวมได้ แต่ไม่เปิด raw student records
- ห้องสอบ เลขที่สอบ และผลสอบจะแสดงเมื่อมีข้อมูลประกาศ/ผลจากแม่กองธรรมแล้ว
- ฟอร์มแม่กองธรรมใช้ไฟล์ต้นฉบับเดิม แยกตรี โท เอก และไม่รวมชั้นหรือสนามสอบ

## แหล่งข้อมูล

| แหล่ง | หน้าที่ |
|---|---|
| Supabase | ฐานข้อมูลหลัก, API, สิทธิ์ และ audit log |
| Firebase | ประวัติใบประกาศเดิมแบบอ่านอย่างเดียว |
| Google Sheets | นำเข้า ตรวจสอบ และส่งออกข้อมูลตาราง |
| Google Drive | เก็บต้นฉบับฟอร์มและรายงานในโฟลเดอร์ที่กำหนด |
| GitHub | โค้ด, schema, migration, CI และ recovery ที่ไม่เปิดเผยข้อมูลส่วนบุคคล |

ไม่ทำ dual-write ระหว่าง Firebase กับ Supabase

## ลำดับพัฒนา

1. สร้าง migration และฐานข้อมูลหลัก
2. ทำ API CRUD และสิทธิ์ผู้ใช้
3. นำเข้า Firebase และรายชื่อนักเรียนปัจจุบัน
4. ทำระบบจับคู่แบบมีสถานะและการตรวจสอบโดยเจ้าหน้าที่
5. ทำกฎสมัครตามปี ระดับ และสายการศึกษา
6. ทำระบบสมัครและ Dashboard
7. นำเข้าผู้มีสิทธิ์สอบ ห้องสอบ เลขที่สอบ และผลสอบตามลำดับ
8. สร้างรายงานโรงเรียนและรายงานแม่กองธรรมจากแม่แบบต้นฉบับ
9. ทดสอบ build, deploy, responsive UI และหน้าเว็บจริงซ้ำจนผ่าน
