# รายงานและฟอร์มส่งออก

## แหล่งฟอร์มแม่กองธรรม

ต้นฉบับถูกคัดลอกแบบไม่แก้ไขไปไว้ในโฟลเดอร์ Google Drive ที่กำหนด ภายใต้ `00_ต้นฉบับฟอร์มแม่กองธรรม` และต้องถือเป็น read-only

- `สำหรับนักเรียน-นักศึกษา-ฆราวาส-ศ.๕-ธรรมศึกษาชั้นตรี_2568-v3.xls`
- `สำหรับนักเรียน-นักศึกษา-ฆราวาส-ศ.๖-ธรรมศึกษาชั้นโท_2568-v3.xls`
- `สำหรับนักเรียน-นักศึกษา-ฆราวาส-ศ.๖-ธรรมศึกษาชั้นเอก_2568-v3.xls`

รายงานแม่กองธรรมต้องสร้างแยกไฟล์ตามระดับ ตรี/โท/เอก และใช้สำเนาของแบบที่ตรงระดับเท่านั้น ห้ามรวมระดับ ห้ามเปลี่ยนลำดับคอลัมน์ ชื่อหัวข้อ การจัดวาง เซลล์ merged หรือรูปแบบต้นฉบับ

ชุดข้อมูลสำหรับเติมแบบใช้ `mother_sangha_form_rows_v3(year, level)` ซึ่งแยกตามระดับและคืนค่าครบทุกช่องของต้นฉบับ รวมช่องประวัติใบประกาศเดิมของชั้นโท/เอกและหมายเหตุ ส่วนช่องที่ไม่มีข้อมูล (เช่น ที่อยู่สังกัดวัดซึ่งยังไม่มีแหล่งอ้างอิง) ต้องเว้นว่างเพื่อให้เจ้าหน้าที่ตรวจทานก่อนส่งจริง

สคริปต์ `scripts/fill-mother-sangha-form.py` รับสำเนา `.xls` และ JSON จาก RPC แล้วสร้าง `.xls` ผลลัพธ์แยกไฟล์ โดยตรวจชื่อชีต ชื่อฟอร์ม หัวคอลัมน์ และ merged ranges ก่อน/หลังการเติมข้อมูล และปฏิเสธการเขียนทับต้นฉบับ การแปลงผ่าน LibreOffice เป็นเพียงสะพานระหว่างรูปแบบไฟล์ จึงต้องเปิดตรวจไฟล์ผลลัพธ์ก่อนอัปโหลดเข้า `03_รายงานส่งออก` ทุกครั้ง

## รายงานโรงเรียน

เป็นรายงานอีกตระกูลหนึ่ง ไม่ใช้แทนแบบแม่กองธรรม และควรมีอย่างน้อย:

- ปีการศึกษา, สายการศึกษา, ชั้น, ห้อง, เลขประจำตัว, ชื่อ-นามสกุล
- ครูที่ปรึกษา 1 และ 2 ตามข้อมูลส่วนหัวของห้อง (หากมีคนเดียวให้เว้นช่องที่สอง)
- ระดับที่สมัคร, สถานะจับคู่ประวัติ, ระดับสูงสุดจากประวัติเดิม
- ระดับที่แนะนำ, เป็นชั้นบังคับหรือไม่, สถานะสมัคร, สิทธิ์สอบ, ห้องสอบ, เลขที่สอบ, ผลสอบ
- สถานะติดตามรายคนและหมายเหตุสำหรับครูที่ปรึกษา

## กติกาความปลอดภัยของข้อมูล

รายงานโรงเรียน คำแนะนำระดับสมัคร และการรันจับคู่ (`refresh_certificate_matches_staff`) เป็นข้อมูล/งานส่วนบุคคล ใช้ได้เฉพาะผู้ใช้ที่ผ่าน Supabase Auth และมีแถว active ใน `staff_roles` เท่านั้น บัญชีเจ้าหน้าที่ต้องถูกเพิ่มโดยผู้ดูแลผ่านช่องทางหลังบ้านก่อนใช้งาน รายงานสาธารณะใช้ได้เฉพาะตัวเลขรวมและสถานะที่ไม่ระบุตัวบุคคล

- Firebase เป็นแหล่งประวัติอ่านอย่างเดียว ไม่เขียนย้อนกลับ
- Google Sheets เป็นพื้นที่ตรวจสอบ/ส่งออกที่ควบคุม ไม่ใช่ source of truth อีกชุด
- รายงานและไฟล์ตรวจสอบเขียนเฉพาะในโฟลเดอร์งานที่กำหนด โดยแยก `01_ข้อมูลตั้งต้น`, `02_นำเข้าและตรวจสอบ`, และ `03_รายงานส่งออก`
- ห้ามส่งออกข้อมูลห้อง 16 หรือนักเรียนที่ออกแล้ว
- ประวัติเดิมไม่มีชั้น/ห้องปัจจุบัน จึงต้องติดสถานะ `review_required` เมื่อชื่อจับคู่ได้หลายรายการหรือยังแยกสาย ม.ต้น/ม.ปลายไม่ได้อย่างปลอดภัย
