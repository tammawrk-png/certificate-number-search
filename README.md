# ระบบค้นเลขใบประกาศ

เว็บค้นข้อมูลผู้ผ่านธรรมศึกษา สำหรับงานธรรมศึกษา โรงเรียนวัดไร่ขิงวิทยา

## แนวทางการทำงาน

- GitHub Pages เป็นโฮสต์หลักของหน้าเว็บ
- Firebase Realtime Database เป็นฐานข้อมูลสำหรับค้นหาแบบเรียลไทม์
- Google Sheet ต้นฉบับใช้เป็นแหล่งข้อมูลหลักสำหรับการนำเข้าข้อมูล
- Google Drive ใช้เก็บเอกสารต้นฉบับและไฟล์สำรอง โดยไม่เผยแพร่ Folder ID ใน Public repository

## ความสามารถของหน้าเว็บ

- ค้นด้วยเลขใบประกาศ ชื่อ นามสกุล หรือบางส่วนของคำค้นหา
- รองรับเลขไทย/เลขอารบิก รวมถึงช่องว่างและขีดที่ไม่เหมือนกัน
- รวมข้อมูลคนเดียวกันที่มีหลายปีหรือหลายระดับไว้ในการ์ดเดียว
- แสดงข้อมูลเป็นระเบียบและเหมาะกับโทรศัพท์ทุกขนาดหน้าจอ
- ดาวน์โหลดผลการค้นหาเป็นภาพ PNG เพื่อเก็บไว้ในโทรศัพท์
- มีสถานะการเชื่อมต่อและข้อความแจ้งเตือนที่อ่านง่าย

## ข้อมูลหน่วยงาน

- งานธรรมศึกษา
- โรงเรียนวัดไร่ขิงวิทยา
- ผู้ประสานงาน: นางหัสยา อุสาหะ ครูกลุ่มสาระสังคมศึกษาฯ
- ห้องธรรมศึกษา 524

## ความปลอดภัย

โปรเจกต์นี้แยกจากระบบเดิมอย่างชัดเจน ไฟล์ `config.js` มีเฉพาะ Firebase Web config ที่จำเป็นต่อหน้าเว็บ ห้ามใส่ service-account key, private key, อีเมลบัญชี หรือรหัสอ้างอิงส่วนตัวลงใน repository
